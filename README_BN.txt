# তেঘরিয়া আল-কারীম ইসলামী যুব সংগঠন — মোবাইল ওয়েব অ্যাপ ডেমো

## মোবাইলেই চালানোর সহজ পদ্ধতি
1. ZIP ফাইল Extract করুন।
2. `index.html` ফাইলটি Acode-এ খুলুন।
3. Acode-এর Preview/Run ব্যবহার করে দেখুন। না হলে ফাইলটি ব্রাউজারে খুলুন।
4. সদস্য নিবন্ধনের ফর্ম পূরণ করে পরীক্ষা করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি HTML/CSS/JavaScript-এর প্রাথমিক ডেমো।
- আবেদন `localStorage`-এ শুধু সেই ডিভাইস/ব্রাউজারে থাকে; অনলাইনে পাঠানো হয় না।
- প্রকৃত সদস্য ব্যবস্থাপনার জন্য Firebase Authentication, Firestore, নিরাপত্তা নিয়ম, অ্যাডমিন অনুমোদন এবং ব্যাকআপ যোগ করতে হবে।
- এই ফাইল নিজে থেকে APK নয়। Android APK তৈরির জন্য পরবর্তী ধাপে ওয়েব অ্যাপকে Android wrapper/PWA পদ্ধতিতে প্যাকেজ করতে হবে; মোবাইল থেকে কাজ করার সুবিধা টুলভেদে আলাদা।
- বাস্তব ব্যক্তিগত তথ্য এই ডেমোতে ব্যবহার করবেন না।
